# UI Specification

## Design language
Calm, dense, trustworthy. White/neutral canvas, strong typography, one accent, almost no decorative chrome. Optimize for comparison rather than ads.

## Search bar
- From (multi-airport allowed)
- To
- One-way / round-trip
- Dates + flexible date toggle
- Travelers
- Cabin(s)
- Advanced: max stops, nearby airports

## Results top area
Show search summary and coverage state:
`4 sources checked · 3 responded · prices last updated moments ago`
Never imply comprehensive coverage unless contractually/measurably justified.

## Primary lenses
- Best trade-off
- Cheapest
- Fastest
- Premium cabin (when relevant)
- Awards (later)

## Result card
1. Airline(s) + operating carrier disclosure
2. Times / airports / duration / stops
3. Cabin/fare brand
4. Total price
5. Warnings
6. 1-3 rank reasons
7. Source/freshness expandable disclosure

## Details drawer
- Segment timeline
- Layover details
- Fare conditions
- Baggage
- Source offers for same itinerary
- Revalidation state

## UX rule
A warning may never be hidden merely because the offer ranks well.
